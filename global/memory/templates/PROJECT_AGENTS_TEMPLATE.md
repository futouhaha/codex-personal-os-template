# 项目 AGENTS.md 模板

这个文件用于生成具体项目的 `AGENTS.md`。

它不是某个项目的最终 `AGENTS.md`。生成具体项目文件时，应根据 Project Onboarding 结果和项目已有结构定制。

项目 `AGENTS.md` 的目标是保持极简：

- 项目识别
- 项目记忆入口
- 项目记忆读取路由
- 必要的项目特殊规则
- 任务结束后的记忆更新提醒

项目 `AGENTS.md` 不是项目计划书、任务看板、工具清单、阶段验收表或项目历史记录。

---

## 生成注意事项

生成具体项目 `AGENTS.md` 时：

1. 不要原样复制本说明部分。
2. 不要为了填满结构而制造内容。
3. 如果项目已有特殊记忆结构，应适配现有结构。
4. 如果项目没有特殊规则，可以省略“项目特殊规则”部分。
5. 当前阶段、下一步、阶段目标、验收标准、命令、工具、浏览器细则，应优先写入项目记忆，而不是写入项目 `AGENTS.md`。
6. 全局安全红线、工具安装、浏览器、Computer Use、记忆写入确认等规则，继承 `~/.codex/AGENTS.md`，不要在项目 `AGENTS.md` 中重复。

## 可选扩展规则

只有当某条信息长期稳定、且每次进入项目都必须先知道时，才可以加入具体项目 `AGENTS.md`。

例如：

- 本项目永远不处理真实用户数据。
- 本项目只生成草稿，不对外发布。
- 本项目禁止移动某个核心目录。
- 本项目必须先读取某个特殊索引文件。

不稳定或阶段性的内容，应写入项目记忆文件。
