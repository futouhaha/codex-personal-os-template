# 全局记忆索引

这个文件是 {{USER_NAME}} 的 Codex 全局记忆文件夹总目录。

全局记忆文件夹位置：

`{{CODEX_GLOBAL_MEMORY_DIR}}/`

这个文件夹用于保存跨项目复用的长期方法、偏好、规则、经验和模板。

它不用于保存某个具体项目的进度、任务日志、临时决策或项目细节。项目相关记忆应保存到对应项目的项目记忆区中，常见为：

`<project>/docs/codex/`

如果某个项目已经有特殊记忆结构，应优先遵守该项目自己的 `AGENTS.md` 和记忆路由。

---

## 1. 使用原则

不要默认读取整个全局记忆文件夹。

使用规则：

1. 先判断当前任务属于哪一类。
2. 根据索引读取最相关的 1 到 2 个文件。
3. 只使用和当前任务相关的内容。
4. 不要把无关旧经验强行套用到新任务。
5. 如果全局记忆和当前项目 `AGENTS.md` 冲突，优先遵守当前项目 `AGENTS.md`。
6. 如果当前项目规则会放宽全局安全红线，优先遵守全局安全红线。
7. 如果全局记忆和用户当前明确指令冲突，优先遵守用户当前指令。
8. 不确定时，先向 {{USER_NAME}} 说明冲突点，再问她如何选择。

## 2. 文件索引

记录 {{USER_NAME}} 的长期协作偏好。

适合读取的情况：

- 需要理解 {{USER_NAME}} 喜欢怎样沟通

### `02_TASK_ROUTING.md`

记录任务判断和任务路由规则。

适合读取的情况：

- 用户问“这个任务该不该进 Codex”
- 任务很模糊，需要判断先讨论还是执行
- 需要判断用 ChatGPT、Codex、浏览器、CLI、Skill、subagent 还是其他工具

- 需要判断任务是否应该项目化

不要在每个普通任务中机械读取它。

如果项目已有成熟项目规则或特殊记忆结构，先尊重现有结构，不强行套默认模板。

## 3. 什么属于全局记忆

适合写入全局记忆的内容：

- {{USER_NAME}} 的长期工作偏好
- {{USER_NAME}} 的沟通和解释偏好
- {{USER_NAME}} 的任务判断方法
- {{USER_NAME}} 的系统设计偏好
- 跨项目复用的工具偏好
- 跨项目复用的安全规则
- 跨项目复用的任务模板
- 跨项目复用的 prompt
- 多个项目反复出现的踩坑和经验
- 未来可能升级为 Skill 的流程

---

## 4. 什么不属于全局记忆

不要写入全局记忆的内容：

- 某个项目的当前进度
- 某个项目的一次性任务日志
- 某个项目的临时想法
- 某个项目的具体 bug 细节
- 某个项目的临时技术选择
- 原始聊天全文
- 无复用价值的执行碎片
- 很快会过期的信息
- 账号、密码、验证码、token、API key、密钥、支付信息、私密聊天、敏感数据

项目相关内容应进入该项目的项目记忆区。

## 5. 和全局 AGENTS.md 的关系

`~/.codex/AGENTS.md` 是全局硬规则和调用入口。  
本文件夹是全局详细记忆和方法库。

如果某条内容满足以下条件，才考虑升级到 `~/.codex/AGENTS.md`：

- 它影响所有项目
- 它是必须遵守的红线
- 如果不遵守可能造成风险
- 它已经被多次验证
- {{USER_NAME}} 明确确认希望长期执行

不要把大量细节写进 `AGENTS.md`。详细规则应保存在本文件夹中，并通过调用表按需读取。

---

## 6. 和项目记忆的关系

每个长期项目可以有自己的项目记忆区，常见为：

`<project>/docs/codex/`

全局记忆和项目记忆的区别：

- 全局记忆回答：“{{USER_NAME}} 通常喜欢怎么合作？”
- 项目记忆回答：“这个项目现在是什么情况？”
- 全局记忆记录跨项目方法。
- 项目记忆记录项目事实和项目历史。

不要把项目进展写进全局记忆。  
不要把全局偏好藏在某个项目记忆里。

如果项目已有特殊记忆结构，应按该项目 `AGENTS.md` 或项目索引文件执行，不强行改成默认 `docs/codex/00–05`。

更新本文件夹中的任何文件前，必须先向 {{USER_NAME}} 提出建议。

建议应包括：

2. 建议新增或修改什么内容
3. 为什么值得记
4. 这是全局记忆、项目记忆、规则、经验、工具策略，还是 prompt
5. 是否有敏感信息风险

等待 {{USER_NAME}} 确认后，再写入。

## 8. 清理规则

全局记忆需要定期清理。

当发现以下情况时，应建议整理：

- 多个文件内容重复
- 规则互相冲突
- 某些内容已经过期
- 某些内容其实只属于项目，不该在全局
- 某些经验已经成熟，应该升级为 Skill
- 某些红线规则应该升级到 `~/.codex/AGENTS.md`
- 某些内容太长，影响检索和使用

清理前必须先给整理方案，等待 {{USER_NAME}} 确认后再修改。
