# Project Memory

This folder is reserved for project-specific Codex memory.

Use it for:

- current project state
- task logs
- decisions
- reusable lessons
- tooling notes

Do not use it for:

- secrets
- passwords
- API keys
- raw private chats
- unreviewed personal memory

Generate the actual project memory files from:

```text
global/memory/templates/PROJECT_MEMORY_FILE_TEMPLATES.md
```
